# Как выпустить «Центр «Практика ТН»» отдельным сайтом

## Что в этом архиве
| Папка / файл | Что это |
|---|---|
| `prototype/index.html` | Текущий рабочий сайт (как на claude.ai), один файл |
| `prototype/src/` | Исходный код по частям + `build.py` (сборка) |
| `data-export/` | Всё, что наставник уже наполнил: урок A1 (лекция, фото, упражнения), настройки и главная, 10 фото |
| `supabase/schema.sql` | Готовая база данных: роли, хранилище, права доступа |
| `CLAUDE.md` | Подробное задание для Claude Code — он читает его сам |

## Что понадобится (всё бесплатно)
1. **GitHub** — хранение кода (github.com).
2. **Supabase** — база данных, вход пользователей, хранилище фото (supabase.com, тариф Free).
3. **Cloudflare Pages** — размещение сайта (pages.cloudflare.com, бесплатно, можно для компании).
4. **Claude Code** — установка по инструкции: https://docs.claude.com/en/docs/claude-code/overview
   (нужен Node.js 18+).

## Шаги
1. **Supabase:** создайте проект → SQL Editor → вставьте весь `supabase/schema.sql` → Run.
   Скопируйте из Settings → API: `Project URL`, `anon key`, `service_role key`.
2. **Папка проекта:** распакуйте архив, например в `C:\praktika-tn`.
3. **Claude Code:** откройте терминал в этой папке, запустите `claude` и вставьте первое сообщение:

   > Прочитай CLAUDE.md и выполни этап 1. Начни с плана, потом создай проект Vite,
   > перенеси код из prototype/src, напиши src/platform.js на Supabase и скрипт импорта.
   > Ключи Supabase я дам в файле .env.

4. Когда Claude Code попросит ключи — создайте файл `.env` в папке проекта:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=...
   SUPABASE_SERVICE_ROLE_KEY=...   # только для импорта, никому не передавать
   ```
5. Проверка на своём компьютере: `npm run dev` → откройте адрес из терминала,
   зарегистрируйтесь своим e-mail.
6. **Сделайте себя владельцем:** Supabase → SQL Editor:
   `update public.profiles set role='owner' where email='ваш@email';`
   Наставникам — `role='mentor'`.
7. **Импорт наполненных материалов:** попросите Claude Code запустить `node scripts/import.mjs`.
8. **Публикация:** загрузите проект на GitHub (Claude Code сделает это командами),
   в Cloudflare Pages → Create → Connect to Git → выберите репозиторий,
   build command `npm run build`, output `dist`, добавьте две переменные `VITE_...`.
   Через 1–2 минуты сайт доступен по адресу `*.pages.dev`; свой домен подключается там же.
9. В Supabase → Authentication → URL Configuration впишите адрес сайта.

## Важно знать
- На новом сайте вход по e-mail, аккаунты claude.ai не нужны. Наставник — по роли в базе, пароль 123456 больше не используется.
- Прогресс абитуриентов из прототипа (тестовые записи) не переносится: у людей будут новые аккаунты.
- Бесплатная база Supabase засыпает после 7 дней без посещений — при регулярном обучении это не проблема; для полной надёжности позже — тариф Pro.
- Пока идёт перенос, рабочая версия на claude.ai продолжает работать. Если наставник добавит материалы там — перед запуском повторите экспорт (попросите меня в этом чате).
